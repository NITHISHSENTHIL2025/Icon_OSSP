Lab Summary: System Calls and System Call Tracing

In this lab, I explored how Linux programs communicate with the operating system kernel using system calls. I learned how file operations are performed through open(), read(), write(), and close(), and how system calls can be traced using strace.

Here is a breakdown of what I learned:

* open(): This system call is used to open an existing file or create a new file. It returns a file descriptor that is used for further operations.

* read(): This system call reads data from a file into a buffer.

* write(): This system call writes data to a file or to standard output.

* close(): This system call closes the file descriptor after the file operation is completed.

* strace: The strace utility traces the system calls generated by a command such as cat sample.txt. It helps to observe how the command communicates with kernel services.

Conclusion

Overall, this practical helped me understand that system calls provide an interface between user programs and the Linux kernel. File operations are performed by requesting the required services from the operating system.
